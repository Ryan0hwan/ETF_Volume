# ETF 특이 거래량 감시

`etfs.txt`의 ETF 75개를 미국 장중 2시간마다 확인해서, 거래량이 평소보다 크게 늘어난 ETF를 디스코드로 알려줍니다.

## 판정 방식

**RVOL = 오늘 지금까지 거래량 ÷ 최근 20거래일의 "같은 시각까지" 평균 거래량**

장 초반과 마감 직전은 원래 거래량이 몰리는 시간대라, 하루 전체 평균과 비교하면 장 초반마다 잘못된 알림이 쏟아집니다. 그래서 오전 11시면 지난 20일의 오전 11시까지 거래량과, 오후 2시면 오후 2시까지 거래량과 비교합니다.

| 조건 | 기준 |
|---|---|
| 알림 | RVOL 2배 이상 |
| 거래 적은 ETF 제외 | 평소 같은 시각까지 거래대금 $100만 미만이면 제외 (잡음 방지) |
| 중복 방지 | 같은 날 같은 ETF는 한 번만. 단, RVOL이 3배 → 5배로 커지면 다시 알림 |

## 디스코드 표 보는 법

```
TICKER 설명              RVOL   등락%  위치%  거래대금  흐름
XLE    에너지             3.2   +1.92     95      1.2B  유입
KWEB   중국 인터넷        2.4   -2.39      4      701M  이탈
```

| 열 | 의미 |
|---|---|
| RVOL | 평소 같은 시각 대비 거래량 배수. 큰 순으로 정렬 |
| 등락% | 전일 종가 대비 |
| 위치% | 당일 저가(0) ~ 고가(100) 중 현재가 위치 |
| 거래대금 | 오늘 지금까지 거래대금 |
| 흐름 | 상승 + 위치 60% 이상 = **유입**, 하락 + 위치 40% 이하 = **이탈**, 나머지 = 혼조 |

흐름은 가격 움직임으로 추정한 것이고, 실제 ETF 설정·환매(자금 유출입) 데이터는 아닙니다.

## 실행 시각 (한국 기준)

**23:35 / 01:35 / 03:35 / 05:35**, 평일 4회. 서머타임 기간(3~11월)에는 마지막 회차가 장 마감 직후라 하루 전체 기준입니다. 시세는 약 15분 지연되고, GitHub 특성상 실행이 5~30분 늦을 수 있습니다.

## 설치 (새 저장소, 약 10분)

1. **디스코드**: 새 채널 생성 (예: `etf-거래량`) → ⚙ → 연동 → 웹후크 → 새 웹후크 → 채널 확인 → URL 복사
2. **GitHub**: New repository (Public) → `etf_volume.py`, `etfs.txt`, `requirements.txt`, `README.md` 업로드 → **Add file → Create new file**로 `.github/workflows/main.yml` 만들고 zip 안의 내용 붙여넣기
3. **Settings → Secrets and variables → Actions → New repository secret**: Name `DISCORD_WEBHOOK_URL`, Secret에 웹후크 주소
4. **Actions → ETF Volume Monitor → Run workflow**로 테스트. 장이 닫혀 있으면 가장 최근 거래일 하루 전체 기준으로 판정하고, 해당 ETF가 없으면 "2배 이상 없음"이 옵니다.

## ETF 추가·삭제

`etfs.txt`를 열어 `티커, 설명` 형식으로 한 줄씩 추가하거나 지우면 됩니다. 차트 목록에 있던 **SPX, SOX**는 지수라서 ETF처럼 거래량이 없어 뺐고, **ISAG**는 정확한 미국 티커를 확인하지 못해 주석으로 남겨 뒀습니다.

## 설정 바꾸기 (`etf_volume.py` 맨 위)

| 항목 | 현재값 | 의미 |
|---|---|---|
| `RVOL_MIN` | 2.0 | 알림 기준 배수 |
| `LEVELS` | 2,3,5 | 같은 날 재알림 단계 |
| `LOOKBACK_DAYS` | 20 | 평소 거래량 비교 기간(거래일) |
| `MIN_AVG_DOLLAR` | 1000000 | 거래 적은 ETF 제외 기준($) |
